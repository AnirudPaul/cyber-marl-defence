Research

Three Papers, One Ecosystem

Each paper attacks a different layer of the problem: how attackers hide, how defenses normalize, and how the two sides learn from each other.

Paper 1 — CPBA

Constraint-Preserving Backdoor Attacks on ML-Based NIDS

Backdoor triggers that respect protocol validity, socket-level realizability, and inter-feature statistics—making them indistinguishable from legitimate traffic.

ASR >96%
Clean Acc >99%
3 Datasets
Paper 2 — PAN

Perturbation-Aware Normalization for Adversarially Robust NIDS

A learnable gate that blends LayerNorm with raw activations— tightening normalization under perturbations and relaxing it for clean inputs. Robustness without sacrificing clean F1.

Clean F1 +39% vs PGD-AT
Params +0.1%
3 Datasets
Paper 3 — ASTRA

Asymmetric RL for Adaptive Adversarial Training in NIDS

A DDPG attacker learns adaptive perturbations; a Dueling-DQN defender trains on those examples via supervised cross-entropy. LayerNorm reduces Jacobian norms by 42×–870×.

Robust F1 0.761
Drop <0.03%
